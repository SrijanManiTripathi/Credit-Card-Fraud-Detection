# 🛡️ Bharat Trust Guard - Credit Card Fraud Detection & Prevention Platform

> **Project Highlight**: This project received outstanding appreciation from the Head of Department (HOD) for its innovative approach to fraud detection and user-centric design.

## 📋 Overview

**Bharat Trust Guard** is a comprehensive, modern web application designed to detect, prevent, and educate users about credit card fraud. Built with cutting-edge technologies, this platform empowers users with tools, knowledge, and real-time fraud checking capabilities to protect their financial assets.

### 🌟 Key Features

- **🔍 Real-time Fraud Detection Tool**: Advanced AI-powered fraud checking system with instant risk assessment
- **📚 Educational Resources**: Comprehensive guides on fraud prevention strategies and security practices
- **📊 Latest Scams Database**: Current information on emerging fraud patterns and scam techniques
- **🗺️ Regional Support Information**: Localized fraud prevention resources and regional regulatory guidance
- **📋 Security Checklist**: Interactive checklist for step-by-step fraud prevention measures
- **⚖️ Regulatory Timeline**: Complete timeline of financial regulations and compliance requirements
- **💬 Professional Footer Support**: Easy access to contact information and support resources
- **🎨 Responsive Design**: Fully responsive UI that works seamlessly across all devices

## 🏗️ Project Architecture

### Tech Stack

- **Frontend Framework**: React 18 with TypeScript
- **Build Tool**: Vite (lightning-fast development experience)
- **UI Components**: Shadcn UI (customizable, accessible components)
- **Styling**: Tailwind CSS (utility-first CSS framework)
- **Form Management**: React Hook Form with Zod validation
- **HTTP Client**: TanStack React Query for efficient API calls
- **Icons**: Lucide React (beautiful, consistent icons)
- **Notifications**: Sonner (elegant toast notifications)
- **Linting**: ESLint for code quality

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or bun package manager

### Installation

```bash
# Step 1: Clone the repository
git clone https://github.com/SrijanManiTripathi/Credit-Card-Fraud-Detection.git

# Step 2: Navigate to the project directory
cd bharat-trust-guard

# Step 3: Install dependencies
npm install
# or using bun
bun install

# Step 4: Start the development server
npm run dev
# or using bun
bun run dev
```

The application will start at `http://localhost:5173` with hot-reload enabled.

### Build for Production

```bash
# Create optimized production build
npm run build

# Preview production build locally
npm run preview
```
